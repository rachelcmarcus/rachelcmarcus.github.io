# Research Portfolio

**Live site:** https://rachelcmarcus.github.io

Applied research projects from my doctoral training in developmental psychology at Penn State, spanning latent class analysis, longitudinal dyadic data processing, and observational behavioral coding. Each project includes full analysis code alongside the rendered output.

## Projects

- **Resilience Analysis** — cumulative risk modeling with Add Health survey data (SPSS data cleaning, R analysis)
- **Baseline Warmth & Synchrony** — CARMA-coded parent-infant warmth import, reliability, and synchrony calculation (R)
- **Still Face Processing** — raw behavioral event log import and episode-boundary validation for the Still Face paradigm (R)
- **Add Health: Profiles & Predictors** — latent class profile and predictor analysis (R)

## Data

Data used in these analyses are protected under the original studies' data use agreement. No raw or identifiable data is present.


Requires R, the packages listed in each project's setup chunk, and Quarto 1.4+.
