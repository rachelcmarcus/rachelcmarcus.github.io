# Research Portfolio

**Live site:** https://rachelcmarcus.github.io

Applied quantitative and behavioral research projects from my doctoral training in developmental psychology at Penn State. The portfolio spans complex survey analysis, person-centered modeling, intensive longitudinal methods, and reproducible behavioral-data pipelines. Each project pairs methodological explanation with reproducible code so the analytic reasoning is visible alongside the results.

## Projects

* **Resilience Across Structural Disadvantage** — Add Health analysis using outcome-specific, empirically weighted disadvantage composites and residual-based resilience scores to examine individual, family, school, and community factors associated with better-than-expected young-adult functioning.
* **Moment-to-Moment Couple Warmth & Synchrony** — second-by-second behavioral coding of couple conflict interactions, including CARMA import, inter-rater reliability, time-series processing, ARIMA pre-whitening, and cross-correlation analysis of dyadic warmth synchrony.
* **Still Face Behavioral Coding Pipeline** — raw-to-analysis-ready processing of 6-month Still Face behavioral event logs, including episode-boundary validation, automated scoring of duration, frequency, and joint attention, and systematic quality checks.
* **Positive & Negative Risk-Taking Profiles** — Add Health latent profile analysis followed by BCH-adjusted multinomial models, moderation analyses, and multiple-comparison-corrected pairwise comparisons; based on Study 1 of my dissertation.

## Data

Data used in these analyses are protected under the original studies' data use agreements. No raw or identifiable participant data are included in this repository.

## Requirements

Requires R, the packages listed in each project's setup chunk, and Quarto 1.4+.
