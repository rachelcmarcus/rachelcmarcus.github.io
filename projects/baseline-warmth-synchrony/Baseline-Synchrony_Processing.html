Baseline Synchrony Processing

  • Show All Code

Overview

This is the second page of a three-page workflow examining moment-to-moment dyadic dynamics in baseline couple interaction warmth. It begins with the validated wide-format baseline warmth dataset created on the Import & Reliability page and prepares the second-by-second trajectories used in the synchrony analysis.

The processing workflow:

  1. reshapes the wide SPSS file from one row per couple with one column per second into one row per couple-second;
  2. recodes the missing-value placeholder to NA;
  3. creates separate positive- and negative-discussion person-level long datasets for mom and partner;
  4. saves the three analysis ready long files used by the synchrony calculation; and
  5. plots warmth trajectories for the full sample and a representative subset as a visual data-quality and interpretive check.
Workflow

1. Import & Reliability → 2. Processing & Visualization → 3. Synchrony Calculation

Transformation

The raw file has one row per couple and separate columns for each second of the interaction (e.g. blmnwh.6, blmnwh.7, …). This section reshapes that into a single long-format table (one row per couple-second), recodes the dataset’s missing-value placeholder to NA, and then splits the negative- and positive-discussion variables into their own person-level long datasets for plotting and later synchrony calculation.

Reshape Wide to Long

code 
# Transform data wide to long
BL_WH_WidetoLong <- BL_WH %>%
  pivot_longer(
    # Select columns like blmnwh.6, blmnwh.7, etc
    cols = matches("^[^.]+\\.\\d+$"), 
    
    # Split variable name based on period
    names_to = c(".value", "second"),  
    names_sep = "\\." ) %>%
  
  # Convert second to numeric
  mutate(second = as.numeric(second))

Recode Missing Values

# Create long format for negative interaction
# (Blmnwh = mom, blfnwh = partner)

BL_WH_Neg_Long <- BL_WH_Long %>%
  select(ID, second, blmnwh, blfnwh) %>%
  tidyr::pivot_longer(
    cols = c(blmnwh, blfnwh),
    names_to = "source",
